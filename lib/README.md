# Bibliotecas externas

Coloque nesta pasta o driver JDBC do SQLite com este nome:

```text
sqlite-jdbc.jar
```

Sugestao de versao estavel:

```text
sqlite-jdbc-3.36.0.3.jar
```

Download:

```text
https://repo1.maven.org/maven2/org/xerial/sqlite-jdbc/3.36.0.3/sqlite-jdbc-3.36.0.3.jar
```

Depois de baixar, renomeie o arquivo para `sqlite-jdbc.jar`.

Para executar a interface grafica com o visual moderno, coloque tambem o FlatLaf com este nome:

```text
flatlaf.jar
```

Sugestao de download:

```text
https://repo1.maven.org/maven2/com/formdev/flatlaf/3.5.4/flatlaf-3.5.4.jar
```

Depois de baixar, renomeie o arquivo para `flatlaf.jar`.
